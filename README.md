# memos-tui

## Description
memos-tui is a commandline text interface for the memos open source app (https://github.com/usememos/memos)
memos-tui provides an interactive text interface to read, create, search and edit memos. It integrates through the official rest api.
memos-tui does not have an inline editor, but instead relies on your own $EDITOR.
memos-tui also allows you to manage tags. It's written in golang, and uses bubbletea for the graphical interface.
